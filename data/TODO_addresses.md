# Researched organisations with no address

These are hand-curated rows (we know they host interns) that carry no street address, so they
appear in the directory but not on the map. Each address is public and takes about a minute to
find on the organisation's own contact page. Fill `address` in `data/institutions.csv`, then run
`python3 data/geocode_precise.py` and they will place themselves.
